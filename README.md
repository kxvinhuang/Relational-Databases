# Relational Databases

This directory contains several PostgreSQL practice databases used to learn relational schema design, SQL queries, and data modeling. Each project focuses on a different real-world or themed domain and includes SQL scripts for creating tables and loading sample data.

## Projects

### Bike_Shop-Database
A small bike rental database with tables for bikes, customers, and rental records. It demonstrates basic inventory tracking and rental history.

### Salon-Database
A salon appointment system for managing customers, services, and appointment bookings. It is useful for practicing one-to-many relationships and scheduling data.

### Students-Database
A student information database linking students to majors and courses. It includes a many-to-many relationship between majors and courses, making it a good example for joins and relational design.

### Universe-Database
A space-themed database with galaxies, stars, planets, and moons. It is designed to practice hierarchical data relationships and table connections.

### World_Cup-Database
A world cup database with teams and match results. It is a straightforward example of relational data for tournament analysis and match tracking.
